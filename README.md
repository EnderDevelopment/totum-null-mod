# Totum of Null Mod

The Totum of Null Mod is a Minecraft mod that introduces a unique block called the Totum of Null. When this block is right-clicked, it spawns Null Soldiers, which are custom mobs with unique behaviors and attributes. This mod is designed for players who enjoy custom mobs and unique gameplay mechanics in Minecraft.

## Install

1. Download the mod file from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure that the mod is loaded correctly.

## Use

1. Craft the Totum of Null block using the provided recipe.
2. Place the Totum of Null block in your world.
3. Right-click the Totum of Null block to spawn Null Soldiers.
4. Command the Null Soldiers by using specific items or commands to control their actions.
